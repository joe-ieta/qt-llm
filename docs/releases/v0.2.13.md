# qt-llm v0.2.13

发布日期：2026-09-23

## 版本定位

`v0.2.13` 补齐 `v0.2.12` 引入的 Provider token 用量语义：用量缺失明确表示未知，而不是 0。该版本保持既有字段读取兼容，只新增可用性标记和对应测试、文档。

## 主要变化

- `LlmUsage` 新增 `available` 标记，Provider 未上报 usage 时为 `false`，token 计数不得按 0 解释。
- OpenAI-compatible 普通与流式响应在存在 `usage` 对象时标记 `available = true`，全 0 用量同样视为已上报。
- 新增 `openAiCompatibleUsageReportsAvailability` 测试，覆盖未上报、完整上报、全 0 上报和流式上报。
- 同步 Provider/运行时设计、请求生命周期、公共契约基线和集成文档。

## 兼容性

- 未移除或重命名字段；`available` 追加在 `LlmUsage` 末尾，保持既有聚合初始化和字段读取兼容。
- 原有直接读取 `usage.inputTokens` 等计数字段的调用方无需修改；未上报时计数仍为 0，但应改用 `available` 区分未知。

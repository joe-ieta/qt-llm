# qt-llm v0.2.11

发布日期：2026-09-13

## 版本定位

`v0.2.11` 完成 qt-llm 基础能力优化工作的质量收尾，统一工程实际能力、公开接口文档和发布验证标准。该版本保持既有代码能力与公开接口兼容，不向基础库引入 CoReader 等上层业务逻辑。

## 主要变化

- 完成 QTL-00 至 QTL-10 工作包，并同步项目路线图、功能矩阵和完成状态。
- 完善 Qt5/Qt6、静态库/动态库、安装包和 `add_subdirectory` 集成说明。
- 明确 `RuntimeFacade`、`ConversationClient`、`ToolEnabledChatEntry` 和 `QtLLMClient` 的职责边界。
- 统一 `Core`、`Diagnostics`、`Tools`、`LocalRuntime`、`Conversation` 和 `QtLlm` 六个 CMake 目标的公开说明。
- 增加公开头文件编译消费者，验证安装后的完整开发接口。
- 增加活跃文档的 UTF-8、标题、链接、状态标记和目标索引检查。
- 将文档检查和公开 API 消费检查纳入发布验证门禁。
- 完善 Qt5/Qt6 命令包装工具的环境选择与命令透传行为。

## 兼容性

- 未移除既有公开类、函数、信号或 CMake 目标。
- 上层应用可继续使用原有接口，并按需迁移到更清晰的分层入口。
- 外部工具执行仍由宿主应用负责；qt-llm 只负责工具调用编排和结果回填。

## 发布验证

- 源码构建矩阵：Qt5/Qt6、静态/动态共 4 组。
- 安装包消费者：20 组。
- `add_subdirectory` 消费者：4 组。
- 文档规范、公开头文件、编译器告警和链接器告警均纳入统一门禁。

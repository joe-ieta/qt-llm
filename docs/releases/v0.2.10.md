# v0.2.10 发布说明

- 发布日期：2026-09-13
- 类型：构建系统与工程文档基线版本

## 主要变化

- 工程构建从 QMake 迁移到 CMake，支持 Qt5 和 Qt6 选择。
- 删除仓库中的 QMake 工程文件和缓存关联。
- 更新根目录、各应用、Agent 和测试目标的构建入口及包装脚本。
- 重整当前文档体系，归档不活跃发布文档并补充项目定位与集成说明。
- 基于 CoReader 实际集成形成 qt-llm 通用基础能力优化方案。
- 将后续开发拆分为 qt-llm 与 CoReader 两套独立工作包及跨项目依赖。

## 兼容性

- 本版本不修改现有 LLM 运行能力和业务接口。
- 外部项目应逐步迁移到 CMake target；后续优化仍保留现有公开入口的兼容路径。
- Qt5 与 Qt6 产物分别构建，不可混用二进制文件。

- CTest：`1/1` 通过，QtTest 共 `41` 项通过、`0` 项失败、`2` 项按运行环境限制跳过

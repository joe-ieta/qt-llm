# v0.2.6

## 重点

- 工具 App 启动时预拉起 managed `llama-server`。
- managed llama.cpp 默认使用 auto GPU offload，传入 `--gpu-layers 999`。
- 增加 GPU backend 库检测和启动参数日志，明确区分 GPU-capable runtime 与 CPU-only runtime。
- 优化 managed runtime 生命周期：端口已有 server 时复用，不重复启动；App 退出时显式停止自己托管的进程。
- 增加重复端口复用和默认 GPU 参数相关测试。
